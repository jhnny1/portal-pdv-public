# Portal PDV

Versões publicadas do **Portal PDV** (frente de caixa com comandas).

- **Programa:** aba [Releases](https://github.com/jhnny1/portal-pdv-public/releases) — `PortalPDV.exe` e o `versao.txt`
  que os programas instalados consultam para se atualizar. Todo arquivo é assinado: o Portal PDV recusa qualquer
  versão sem a assinatura certa.
- **Manual:** pasta [`manual/`](manual/) — manual completo e guia rápido em PDF. O programa abre a versão mais nova
  (engrenagem > Ajuda).
