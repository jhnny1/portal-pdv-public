# Portal PDV

Versões publicadas do **Portal PDV** (frente de caixa com comandas).

Este repositório guarda só o programa pronto (`PortalPDV.exe`) e o `versao.txt` que os
programas instalados consultam para se atualizar. Todo arquivo é assinado: o Portal PDV
recusa qualquer versão que não tenha a assinatura certa.
